# v3評価計画：未知資料・独立人間評価・設計支援・体験差

作成日：2026年10月4日。状態：未実施の計画案。

対象は [v3設計レポート](../baseline/v3-proposed/report.md) の操作的語彙である。既存の [v1調査方法](validation.md) と過去の対応表を変更しない。131項目はdevelopment/training corpusとして語彙の開発に利用済みで、独立test setではない。trainingは語彙と運用規則の開発を指し、AIモデルの訓練を意味しない。

## 1. 評価する仮説と、現在の証拠

| 評価対象 | 評価する仮説 | 現状 |
|---|---|---|
| 記述と符号化 | 固定した条件で、人間評価者が同じ根拠から同じ問題状態・前提変更を識別できる | AI5群と統合担当AIの探索分析のみ。独立人間評価・一致度未測定 |
| 区別の価値 | 型を分けると必要情報・使える行動・準備項目の判断が変わる | 開発資料上の記述経験のみ。外部基準で未評価 |
| GM設計支援 | v3利用によって設計の見落としや混同が減り、準備負担に見合う効果がある | 比較試験未実施 |
| プレイヤー体験 | v3利用や情報・選択の設計差によって体験に差が生じる | 怖さ・主体性等の測定未実施 |

26項目が恐怖心理の自然分類であるかは本計画の仮説に含めない。怖さが生じなくても問題状態は成立し得る。分類の一致が高くても、設計効果と体験効果の支持へ自動的に拡張しない。

## 2. test資料を見る前に固定するもの

v3は現時点では提案版である。実施に先立ち、レポート、型ごとの必須条件、補助条件、場面の区切り方、対象と世界層の指定、陰性例、記録様式、集計方法をcommitとハッシュで固定する。固定した基準ID、commit、各文書のハッシュ、固定日時を評価記録へ残す。文書のprovenanceは今回の改訂の追跡用であり、この研究手順の固定を代替しない。

必須条件はレポート3.1〜3.8節を起点にする。表中の複数条件はそれぞれ根拠を要求し、例示された全行動を取ったことや、安全な結末を迎えたことは要求しない。設計用に提案できる対処・閉鎖条件と、本文が実際に示した条件も分ける。F群では旧前提、新証拠、証拠範囲、当事者の受容・脅威認識、局所説明では足りない理由、代替仮説を共通の必須記録とする。

補助条件は、必須条件を満たす範囲で比較したい追加の対応である。型の特徴を成立させる条件を補助条件へ下げない。現提案では補助条件の型別一覧が未固定のため、それを定めるまでは新規符号化に部分適合を使わない。閉鎖未達成や一つの推奨行動を使わなかっただけで部分適合としない。

指標、資料選定数、人間評価者数、集計単位、採否基準、効果量・標本数の設計は未決定である。実施者がtest結果を見る前に決定し、その理由を記録する。現在の資料から数値を補完しない。

## 3. 未知コーパスと開発資料を分ける

語彙の定義を固定してから、定義の調整に用いていない本文と版を確保する。可能なら、資料選定担当が本文を管理し、基準を調整する担当にはtest内容を開示しない。今回の131項目、コトリバコ、旧版の映画・ゲーム・小説の例示、同じ話の転載・異名・系列との重複を確認する。独立性が未確定なら保留し、件数から消さず理由を残す。

開発用の訓練資料で記録方法を調整し、test資料では相互相談・定義変更を行わない。test結果を見て規則を改訂する場合、その資料は次版の開発資料となり、改訂後の評価には別の未知資料が必要である。

資料の版、本文範囲、確認状態、系列・異名、文化圏、媒体、抽出方法を記録する。本文不足は分類の不適合と区別する。場面は作品内、作品は系列や資料源内で相関し得るため、行数を独立標本数と表示しない。標本・推定・区間評価を行う場合は、作品／系列等の単位を事前に定める。

自然な出現頻度を調べるtestと、D2・F群等の境界を重点的に点検する課題セットを分ける。後者には支持候補と似た陰性例を選定規則に従って含める。候補が実際に適合するかは独立評価に委ね、課題セットの比率を一般コーパスの頻度・網羅率へ読み替えない。

## 4. 独立した人間評価者による再符号化

複数の人間評価者が同じ固定資料を読める割当を用意する。相互のラベル、過去のAIラベル、期待される陽性判定を見ない状態で記録する。独立記録を保存してから合議・裁定を行い、合議結果を一致度へ代用しない。AI5群の分担は同一資料への独立評価ではなく、同じ基準・文脈による誤差の相関もあり得る。今回の提出数から一致度や独立評価者数を算出しない。

先に当事者、時点、世界層、対象、予期損失、その根拠、行動、前提を抽出する。後にA〜Eの主型・副型を判定し、F群は別欄へ記す。全場面に型を強制せず、F群だけが根拠を持つ場面、型なしの不気味さ、未分類の問題状態も保持する。

| 記録単位 | 残す内容 |
|---|---|
| 資料・場面 | 版、本文範囲、作品／系列／場面ID、区切りの理由、確認状態 |
| 必須条件ごと | 本文根拠の短い自作要約、観測／伝聞／推測、根拠あり／明示的不成立／判断不能 |
| 型ごと | A〜EかF群か、判定、主型／副型／候補、競合型、反対根拠 |
| Q／D／C／M | 問い、設定上・認識上の危険、実行可能・認識された行動、旧前提と更新 |
| 残余 | 未分類の問題状態、定義域外、資料不足、修飾のみで記述した部分 |
| 提示・情動 | 提示の内容・方法、反応の狙い、観察した反応、観察方法、未測定 |

## 5. 適合・部分適合・不適合・保留の厳格化

資料の確認状態と型への適合は別軸で記録する。型なしも単一の成功・失敗へまとめない。

| 判定 | v3での条件 | 集計上の扱い |
|---|---|---|
| 適合 | 固定範囲で全必須条件に根拠があり、明示的な矛盾がない。補助的対応を事前指定した場合は、その対応にも不一致がない | 型ごとの陽性。副型にも同じ条件を適用 |
| 部分適合 | 全必須条件が固定範囲で成立し、事前指定した補助的対応の一部が一致しない | 非陽性。欠けた対応を記録。補助条件未固定の型では使用しない |
| 不適合 | 確認可能な資料が型の必須条件を明示的に否定する | 型ごとの陰性。資料不足とは別 |
| 資料不足・判定保留 | 必須条件の真偽を判断できる本文根拠が不足する | 欠測・保留。候補を付けても非陽性 |
| 定義域外 | 確認範囲に具体的な予期損失等の対象条件がなく、不気味さ等を別に記述する | 型による説明成功へ加算しない |
| 未分類の問題状態 | 予期損失と問題は確認できるが、既存項目では必要な区別が足りない | 語彙の不足候補として保持 |

不適合の行を型なしへ移して残余を消さない。修飾欄・演出欄へ記入できたことも型の支持に数えない。F2の陽性は、構造的限界への認識が本文根拠を持つという判定であり、人類に永久に理解不能であることの証明ではない。

既存の適合75・部分適合141・不適合17は、v1の場面全体判定の記録である。複合場面のfitから個々の型の陽性を逆算せず、新基準の判定へ変換しない。v3の部分適合と同じ意味で集計しない。

## 6. 分析者間一致と反証の記録

場面区切りの一致と、同一場面の判定一致を別に評価する。固定した場面単位を共有する評価と、独立に場面を抽出する評価を混同しない。A〜Eのラベル集合、主型・副型、F群、型別陽性・陰性・保留を分け、単純な全一致だけでなく陽性の一致と混同表も示す。

一致度指標、複数ラベルの比較方法、低頻度ラベルへの対応、欠測・保留の分母、集計単位は事前に指定する。F群でほぼ全て陰性になれば、陰性一致は高くても陽性識別の再現性は確認できない。保留を除いた値だけでなく、保留の数・理由と全割当の内訳を報告する。指標の具体的な選択は実施前に残す課題である。

資料が十分でも未分類が反復する、必須条件の解釈が独立評価者間で安定しない、型を区別しても外部の設計判断が変わらない、といった結果を改訂の根拠とする。testで見つけた例外をその場で追加して成功扱いしない。E4と対処能力、C4と損失対象、F群とMタグ、D5とD1・D2、E5とE3・E4を比較候補として残す。

## 7. GM設計支援の比較

同じ設計課題についてv3利用条件と非利用条件を設ける。割当方法、GM経験、課題の順序・難度、準備時間、条件間の学習持越しをどう扱うかを事前に決める。可能なら作成条件を知らない評価者が、型名を伏せた設計物を評価する。

評価対象は、必要情報の欠落、選択の実効性、Q解明とD回避の混同、対処・決着の範囲、成果の固定、準備時間・負担である。型の記入数やv3用語との一致だけを採点基準にしない。設計課題と採点基準を事前に公開可能な形で固定し、独立した採点の一致も記録する。

A1とA2の識別が感知根拠と接触経路の準備を、D1とD5の識別が検査・摘出と損傷停止の準備を、E4とE5の識別が実行資源と継続管理の準備を変えるかを比較する。閉鎖条件が異なると定義しただけでは効果を示せない。条件差がなかった結果や、細分化で準備負担が増した結果も残す。

## 8. プレイヤー体験差の比較

GM設計支援試験と体験試験は別に記録する。v3利用の効果を調べる比較と、情報・選択・演出を変える比較を分ける。後者は同じ問題状態で提示だけを変える条件と、提示をそろえて情報・選択を変える条件を区別し、複数の要因を一度に変えて原因を断定しない。

危険認識、予期した損失、可能だと思った行動、恐怖、不気味さ、嫌悪、驚き、悲嘆、達成感、納得、主体性を別に観察する。測定手段と時点、脅威の強さ、時間、判定難度、GM進行、プレイヤー経験、卓内の相関を扱う方法を事前に定める。型の成立から怖さを推定しない。

安全な解決、未解決、損失による終結を区別する。非解決や型なしの不気味さを失敗と決めつけず、解決感と恐怖・残響の両方を評価する。v3利用条件で差がない、怖さが低い、主体性は高い、といった異なる結果もそのまま残す。

## 9. 実施前に残る作業

未知資料の確保と独立性確認、独立した人間評価者の確保、必須・補助条件の型別固定、記録様式、指標・採否基準、標本数、GM課題と採点基準、体験測定の方法は未完了である。現時点で研究結果や成功率はない。構造検査と文書整合性検査は、この計画の妥当性・実施・効果を証明しない。
