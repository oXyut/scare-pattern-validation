## 要旨

本稿は、ホラーTRPGで当事者が予期する損失と、その回避・確認・受容をめぐる問題を記述する設計語彙を提案する。26型の中心命題は、GMの設計判断を変える操作的語彙として使えるかという仮説である。恐怖心理の自然分類、独立した26因子、ホラー判別器としての妥当性は主張しない。問いQ、危険D、選択C、世界モデルMを人間向けの簡略記法として継承し、それぞれの理論的役割を分ける。

既存の六群・26 IDを保持し、A〜Eの問題状態、F群の世界モデル破綻、横断的な修飾軸、提示演出、情動反応を分ける。同じ場面に複数の問題と前提変更を記録できる。型名や閉鎖条件を定義したこと自体は、その区別の妥当性を示す証拠にならない。区別によって必要情報、行動可能性、GMの準備項目が変わるかを外部基準で評価する。

## 1. 分類するもの

### 1.1 予期的問題状態と設計語彙の定義

本稿では予期的問題状態を、当事者が望ましくない帰結を予期し、その回避・確認・受容をめぐって置かれる、反復可能な問題状態とする。A〜Eはその記述項目であり、F群は当事者の世界理解に関する前提変更を別に記述する。

操作的語彙としての型は、GMが必要情報、使える行動、損失の範囲、対処・決着条件を準備する際に、異なる判断を促すための暫定的な区別である。26項目が最小であることや、各項目が実際に独立した設計上の利点を持つことは未実証である。

「ゾンビ」「幽霊」「殺人鬼」は脅威の担い手であり、型そのものではない。同じ幽霊でも、隠れる、追われる、家に侵入される、身体を奪われる、家族に化けられる、という異なる問題を作れる。逆に「見つかりそう」は、怪物にも人間の追手にも適用できる。

問題状態だけでホラー体験が成立するわけではない。発見回避はスパイ作品にも、追跡回避はアクションにも現れる。本稿の分類は、恐怖を狙う場面の構造を記述するためのものであり、ホラーと他ジャンルを自動判別する定義ではない。損失への関心、脆弱性の認識、演出、人物への愛着などは別途必要になる。

### 1.2 問題状態の主型・副型と、F群の別記録

まず、場面内の当事者・時点・対象と、予期損失を支える本文根拠を特定する。型名を付ける前に、何が未解決かを記録する。次に「一つだけ条件を変えるなら、何を変えればこの場面の中心的な問題が低減するか」を問う。これは反実仮想による記述補助であり、実測した情動反応ではない。

- 追手の感知から外れれば低下する：A1「見つかりそう」。
- 追手との接触を回避すれば低下する：A2「追われている」。
- 現在地と帰路の見当がつけば低下する：B1「知らない場所にいる」。
- 位置が分かっても扉が開かなければ低下しない：B2「閉じ込められている」も存在する。

この判定は分析上の仮説である。実際の発言や行動で確認できなければ「主型候補」と記録する。複数の問題が同程度に重要なら、無理に一つの主型へ絞らない。A〜E内の主型・副型と、F群の前提変更は別欄に記す。F群だけが根拠を持つ場合もA〜Eのラベルを強制しない。

閉鎖条件の違いは本稿が置いた定義上の区別である。その違いを理由に型を定義し、同じ違いを型の妥当性の証拠に使うと循環する。A1とA2の区別が必要情報・行動設計・準備の見落としを変えるかは、第8章の独立符号化とGM比較で確かめる。設計時に置いた閉鎖条件と、作品内で確認した条件も区別する。

26型は心理学的に独立した26因子ではない。使い分けを試すための暫定的な設計目録である。六群も理解を助ける見出しであり、自然界に存在する六つの恐怖系統という主張ではない。

## 2. Q／D／C／Mの役割：発生と決着を分解する

本稿のQ／D／C／Mは、継承元の情報設計レポートv2 [S0] に由来する。「情報設計v2」と「26型v2」は別の版である。四つは同格の状態変数や測定尺度ではなく、次の役割が異なる記述欄である。

| 記法 | 理論的役割 | 記述上の区別 |
|---|---|---|
| Q：問い | 当事者の情報不足を、答えを求める命題として取り出す | Mに関わる未確定部分でもある。Qの解明を世界の変化と同一視しない |
| D：危険 | 望ましくない帰結と、その発生条件・予期を追う | 設定上の危険と当事者の危険認識を別記する。損失の価値や重さも別情報 |
| C：選択 | 行動候補、実行条件、認識している帰結と代償を追う | 実行可能な行動と、当事者が可能だと思う行動を区別する |
| M：世界モデル | 安全、自己、他者、因果、人間の立場に関する当事者の信念・前提を追う | 世界そのものと当事者のモデルは異なる。局所的更新の全てがF群ではない |

| 追跡対象 | 問題の発生として記録する変化 | 閉じる・決着するとして記録する変化 |
|---|---|---|
| Q：問い | 状況、原因、正体、規則に関する問いが開く。証拠が矛盾する | 対象の問いに、根拠を伴う答えが得られる |
| D：危険 | 損失が生じ得る。既存の危険が認識される。切迫する | 指定した損失の発生条件が除去・回避される |
| C：選択 | 行動の帰結が不明になる。実行可能性が下がる。代償が分かる | 選択を実行し、結果と残る未確定部分が明らかになる |
| M：世界モデル | 安全、自己、他者、因果、人間の立場についての前提が揺らぐ | 前提が回復・限定・棄却・再構成される。態度を決める |

### 2.1 発生経路は一つではない

1. **世界の変化：** 扉が施錠される、追手が接近する、身体の変化が進む。
2. **危険の認識：** 既に飲んだ水が汚染されていたと判明する。情報取得前から設定上の危険はあった。
3. **選択の変化：** 逃げ道が塞がる、救助の代償が判明する。
4. **前提の変化：** 助けている装置の目的が、人間の利用だったと分かる。

「新しい情報が出たから恐怖が発生した」だけでは、これらを区別できない。情報内容、提示方法、世界の出来事を別々に記録する。

### 2.2 五つの終わり方

| 終わり方 | 例 | 誤認しやすい点 |
|---|---|---|
| 問いの解明 | 怪物は音を感知すると分かる | 規則を知っても、近くにいる怪物は消えない |
| 危険の回避・除去 | 感知範囲から離れる、感染を治療する | 一時的な回避と原因の根絶は別 |
| 選択への決着 | 代償を理解して救助を実行する | 決断しただけで被害が消えるとは限らない |
| 世界モデルへの決着 | 「安全は条件付き」と理解を更新する | 理解の更新は安心の回復を保証しない |
| 損失による終結 | 被害が確定し、予期していた事態が終わる | 緊張の終結は、成功・安全・良い体験と同義ではない |

「怪物が見えなくなった」は観測の変化であり、回避の証拠とは限らない。「怪物がいないと分かった」場合も、どの場所・時点・観測条件について確認したかを残す。

死や喪失後には、予期的な恐怖から悲嘆や嫌悪へ体験が変わることもある。この変化まで同じ緊張の持続とみなさない。

### 2.3 意思決定を記述するための対応案

設計記録を詳しくする場合は、設定上の世界状態、観測・情報、当事者の信念、損失への価値判断、利用可能な行動を分ける。観測はMを更新し、そのうち未確定で行動に関わる命題をQとして記す。世界状態・行動・損失評価から、設定上のDと認識されたDを別に記述する。Cには、世界条件の下で実行できる行動と、当事者が認識している行動集合の両方を記す。

これは本稿の簡略記法を整理する対応案であり、既存の意思決定理論への形式的な同値性を示すものではない。確率分布、効用関数、状態遷移の推定値は本資料では定義・測定していない。QはMに含まれる情報不足として解釈でき、Dは世界条件と価値判断に依存するため、四記法を独立な数値として加算しない。

## 3. 六群・26 IDの設計語彙

以下は主に当事者側の記録である。3.1〜3.5節は問題状態22項目、3.6節は別階層の世界モデル破綻4項目である。型名・IDとA〜Eの定義表はv2から保持した。各列のQ／D／C／Mは記述欄であり、F群にMの更新が記されていても、他群と同格の型だという意味ではない。

表中の「閉じる条件」は設計可能な条件であり、その型を使う作品が必ず安全に終わるという意味ではない。Qが解明される条件とDが閉じる条件を併記する。閉鎖条件は安全な結末を義務づけず、未達成・不明・損失による終結も記録できる。

### 3.1 A群：捕捉と侵入

| ID・型 | 発生条件・中心的なQ／D | 主なC | 閉じる条件 | Mと次の型への接続 |
|---|---|---|---|---|
| A1 見つかりそう | 自分の所在を追手がまだ確実には把握していない。Q：何が感知されるか。D：発見後の捕捉・加害 | 隠れる、音を止める、囮を使う、移動する | Q：感知条件の確認。D：今回の捜索をやり過ごし、対象範囲で捕捉の可能性を下げる | 隠れ場所への信頼が条件付きになる。発見されればA2へ |
| A2 追われている | 追手が自分を標的として接近する。Q：速度、経路、障害物への反応。D：接触・捕獲 | 逃げる、足止めする、経路を変える、交渉する | Q：追跡規則の確認。D：追跡を振り切る、接触不能にする。制限時間付きなら明示 | 距離の意味が変わる。視線を切って捜索状態になればA1へ |
| A3 安全な場所に入ってこられる | 守られていると思っていた領域に脅威が侵入する。Q：どこから入り、何が境界を守るか。D：生活・避難領域での加害 | 出入口を塞ぐ、退避する、侵入者を排除する | Q：侵入経路の特定。D：排除と再侵入防止、またはその場所を離れる | 「家・避難所は安全」が限定される。A4やC2へ |
| A4 囲まれ、じわじわ突破される | 脅威が周囲を占め、境界や資源が保たなくなる。Q：どこがいつ破られるか。D：突破・消耗 | 補強する、救援を呼ぶ、突破する、資源を配分する | Q：防衛条件の把握。D：包囲を解く、脱出する、救援まで維持する | 防御・備蓄への信頼が試される。突破後はA2、退路喪失はB2へ |

**境界：** A1は情報の捕捉、A2は標的への接近、A3は安全境界の破れ、A4は境界を維持する競争が中心である。姿が見えない追手でも、標的への接近が確かならA2になる。追手が既に所在を知っているのに単に隠れている場面を、自動的にA1とはしない。

### 3.2 B群：空間と認識

| ID・型 | 発生条件・中心的なQ／D | 主なC | 閉じる条件 | Mと次の型への接続 |
|---|---|---|---|---|
| B1 気がついたら知らない場所にいる | 現在地、来た経緯、周囲の安全条件を把握できない。Q：ここはどこか、どう戻るか。D：未知の環境での損失を予期 | 周囲を調べる、記憶を確認する、移動する、人を探す | Q：当面の状況と帰路・滞在条件の把握。D：環境の危険は別途対処 | 日常の連続性が揺らぐ。出口がないと分かればB2、空間が変わればB3へ |
| B2 閉じ込められている | 外へ出たいが、物理的・制度的・怪異的な障壁がある。Q：脱出条件。D：滞在中の加害・窒息等 | 解錠する、別経路を探す、協力する、障壁を壊す | Q：脱出方法の特定。D：安全な外部への到達。単に扉が開くこととは区別 | 「望めば離脱できる」が崩れる。脱出時にA2やA4へ |
| B3 道や時間が正常につながらない | 同じ場所へ戻る、部屋の接続が変わる、時間が反復する。Q：移動・反復の規則。D：帰還不能や消耗 | 印を付ける、記録する、条件を変えて試す | Q：使える規則の把握。D：反復・迷路から脱出する、または安全な滞在を確保 | 座標・順序への前提が限定される。証拠が広く一般化できるときだけF1候補 |
| B4 見聞きしたものを信用できない | 知覚、記録、証言に食い違いがあり、判断を誤ると損失が出る。Q：何を根拠に採用するか。D：誤判断 | 別の感覚・人物・記録で照合する、判断を保留する | Q：対象命題について独立した根拠を確保。D：不確実性を織り込んで行動する | 認識の信頼条件が変わる。原因が記憶改変ならD4、能力限界の証拠ならF2へ |

**境界：** B1は状況の不明、B2は離脱の阻害、B3は空間・時間の接続規則、B4は判断根拠の信頼性に関する問題である。暗い部屋で目覚めただけなら、好奇心や驚きにとどまり得る。恐怖として使うには、孤立、戻れない可能性、負傷の痕跡など、当事者に重要な損失との接続を設計する。

### 3.3 C群：他者と関係

| ID・型 | 発生条件・中心的なQ／D | 主なC | 閉じる条件 | Mと次の型への接続 |
|---|---|---|---|---|
| C1 目の前の人が本人ではないかもしれない | 外見・声・記憶を似せる存在がいる。Q：誰が本人か。D：接近を許した脅威からの加害 | 検査する、隔離する、合言葉を使う、距離を置く | Q：特定人物を、特定時点・精度で同定。D：危険な代替者との接触を防ぐ | 外見と人格の対応が揺らぐ。検査で露見すればA2やD1へ |
| C2 味方や共同体が自分を害そうとしている | 本人である他者の利害が敵対している。Q：誰の目的は何か。D：裏切り、拘束、供犠 | 目的を調べる、交渉する、離脱する、別の支援を得る | Q：利害・計画の把握。D：計画から逃れる、阻止する | 援助・権威への信頼が変わる。B2やA4へ |
| C3 危険を訴えても信じてもらえない | 当事者が根拠を持っていても他者が受容せず、援助が得られない。Q：何なら伝わるか。D：孤立による被害 | 証拠を見せる、別の支援先を探す、自力で対処する | C：必要な協力を確保、または協力なしで対処できる。相手を説得すること自体は必須ではない | 社会的な安全網への信頼が限定される。救援なしのA4へ |
| C4 大切な人を失いそう・助けられない | 自分以外の重要な対象が危険にあり、介入が難しい。Q：所在、被害、救助条件。D：他者の喪失 | 救出する、代替支援を頼む、危険を引き受ける | Q：救助条件の把握。D：指定した対象の救出・保護。死亡確認は損失による終結 | 他者を守れるという前提が試される。救助の代償が分かればE3へ |

**境界：** C1は同一性、C2は利害、C3は証拠の社会的受容、C4は守りたい対象に関する問題である。C1の検査に成功してもC2は閉じない。人間本人でも敵対し得るからである。B4とC3も、本人が確信できないことと、他者が信じないことの違いがある。

### 3.4 D群：身体と自己

|---|---|---|---|---|
| D1 体内に何か入った・感染したかもしれない | 寄生・感染・異物の侵入を示す接触や症状がある。Q：何が入り、どう進むか。D：発症、身体損傷、他者への伝播 | 検査する、治療する、隔離する、摘出する | Q：感染等の有無・性質の確認。D：除去・治療、または進行を抑えた条件付き安定 | 身体の境界への信頼が揺らぐ。D2やE2へ |

| D4 自分の記憶・人格・存在が自分のものではない | 複製、記憶の埋め込み、置換などの証拠がある。Q：自分の由来と継続条件。D：人格の消失・置換やその予期 | 記録を検証する、処置を選ぶ、他者との関係を決める | Q：由来・仕組みの解明。M：自己理解の再構成。C：今後の態度の決着。消失危険は別途追跡 | 自己の連続性が揺らぐ。一般的な人間理解まで変わればF群候補 |
| D5 身体が内側から壊される | 内部の損傷・痛み・機能低下が進行し、その停止を自分で制御できない。Q：何が起き、どこまで進むか。D：臓器損傷・機能喪失・死 | 原因を調べる、進行を止める、治療を受ける、救助を求める | Q：原因・進行・対処条件の把握。D：損傷の進行停止と生存の確保。既存の損傷回復は別に記録 | 「外傷が見えなければ身体は安全」という前提が限定され得る。侵入原因が分かればD1と併記。重篤化すればC4やE4へ |

### 3.5 E群：因果と選択

|---|---|---|---|---|
| E1 ある条件を満たすと災厄が来る | 接触・禁忌・契約等で危険が起動する。Q：発動条件と停止条件。D：遅れて到来する損失 | 条件を避ける、解除する、猶予を得る、退避する | Q：規則の把握。D：条件の解除、効果の遮断。期限が来ていないだけでは解決しない | 行為と安全の結び付きが変わる。具体的な追手ならA2へ |
| E2 危険が他者や別の場所へ広がる | 感染、媒介、呪い等が新しい対象へ及ぶ。Q：伝播経路。D：被害対象の増加 | 媒介を断つ、隔離する、警告する、伝播先を守る | Q：伝播規則の把握。D：対象範囲で伝播を止め、既存被害にも対処 | 「自分が助かれば終わる」が限定される。C4やE3へ |

| E5 危険を抱え、管理し続けなければならない | 危険を当面抑える方法はあるが、継続的な保管・監視・手入れ・継承が必要で、放棄や失敗が自他を害する。Q：安全条件と管理を終える条件。D：管理破綻による被害。C：離脱の困難と責任 | 管理を続ける、協力者を確保する、無害化を探す、情報と能力を備えた相手へ責任を移す | D：条件を満たす管理で当面の被害を回避。継続義務は残る。無害化または安全な責任移管により当事者の管理問題を閉じる。移管後も全体の危険は残り得る | 「知れば距離を置ける」「自分が去れば終わる」が限定され得る。負担逃れで他者を危険にさらせばC2、破綻時はE1・E2・C4へ |

**境界：** E1は起動条件、E2は被害の移転・増殖、E3は対処の代償、E4は実行可能性の不足、E5は危険を抑え続ける管理と離脱の条件である。E4は有効な対処を実行できない問題だが、E5は対処を実行できても終われない問題である。E3の代償が継続する場合と重なることはあるが、E5では監視・引き継ぎ・責任移管を別途準備する。安全な責任移管には、引受人の理解・同意・能力と情報の継承が必要であり、知らない相手への押し付けを解決としない。「解決したと思ったら効いていなかった」は新たな独立型にせず、閉鎖条件の誤認からE1・E4などが再認識される遷移として記録する。

### 3.6 F群：世界モデル破綻の記述項目「人間と世界」

F群は、継承元の情報設計v2にある宇宙的恐怖の候補を、世界モデル破綻として記述する。全てについて、旧前提、変更を促す証拠、当事者にとっての脅威が必要である。設定の奇妙さや敵の強さだけでは該当しない。

ここでの「破綻」は、当事者の前提を従来どおり維持できなくなることを指す。作中世界の基本規則が実際に変化したことや、当事者の信念が客観的に真であることを一律に意味しない。局所的な知識更新はM欄に残し、F群の成立とは分ける。

| ID・型 | 発生条件・中心的なQ／D／M | 主なC | 決着の候補 | 他型との境界 |
|---|---|---|---|---|
| F1 世界の基本規則が、自分たちの理解と違う | 複数の信頼できる証拠が、因果・時空・生死などの前提を覆し、安全判断も変える | 新しい規則を調べる、局所条件で対処する、関与を避ける | Q：局所規則の解明。M：説明の再構成。D：今回の被害への対処 | 一つの迷路の規則だけならB3。超常現象が出ただけでは不十分 |
| F2 人間には、理解・制御できない領域がある | 工夫や反復検証を経ても、人間の認識・能力の構造的限界を示す証拠がある | 扱う範囲を限定する、道具・協力を試す、撤退する | 限界が反証されれば前提回復。残るならMの限定とCの態度の決着 | 手帳が読めない、武器がない、といった今回の障害はE4やB4 |
| F3 人間の価値や願いが、世界では重視されていない | 善意・正義・尊厳が、脅威の挙動や秩序に関係しないと判明し、人間の立場が揺らぐ | 人間同士の価値を守る、救済への期待を改める、退避する | M：人間の価値と世界の挙動を分けて再構成。C：守るものを決める | 残酷な一人の敵だけならC2。価値の非中心性に関する理解が必要 |
| F4 人間の安全・歴史・存在が、別の存在の用途に従属している | 保護や日常の成立が、人間を素材・設備・資源として利用する仕組みだと示される | 依存を断つ、代替を作る、条件付きで利用する、抵抗する | Q：依存関係の理解。D：今回の被害対処。M：立場の再構成。C：依存への態度の決着 | C2の陰謀より広い、人間の成立条件に関する前提変更を対象にする |

F3とF4は「無関心」と「利用」の違いである。人間が宇宙に重視されないことと、人間が何かの目的のために維持されていることは、異なる理解と選択を生む。

F群の解明は恐怖を減らすとは限らない。しかし、再構成や態度の決着を必ず終盤まで遅らせる必要もない。取得順と選択の実行可能性に従って扱う。

### 3.7 継承する判定境界：成立条件と陰性例

以下は横断レビュー [S12–S13] に基づく暫定運用規則である。第3章の型を広げて全例を収容するための例外ではない。v3では第8章の判定手順に従い、必須条件の不足を部分適合で陽性扱いしない。候補、部分適合、不適合、資料不足、定義域外を区別する。

| 型 | 適用前に確認する条件 | 単独では足りない例・区別先 |
|---|---|---|
| A1 | 所在が未捕捉で、発見回避が問題になる | 公的露見、個体の同定だけは損失・情報露出欄へ。所在の発見と同一視しない |
| A2 | 標的への方向性ある接近と接触危険 | 目撃・通過・瞬間的な暴行だけでは追跡としない |
| A3 | 安全だと期待した領域の境界を脅威が越える | 窓の外への接近、電話での露見は物理侵入と区別。通信境界への拡張は保留 |
| A4 | 包囲下で境界を維持し、突破・消耗を防ぐ | 有限の待機、内側の怪異の封じ込めを自動分類しない |
| B1 | 所在・経緯・帰路の不明が予期損失に結び付く | 知っている場所での出口遮断はB2 |
| B2 | 離脱を阻む障壁がある | 普通の待機や怖くて動けない心理だけでは足りない |
| B3 | 空間接続・時間差・反復の異常を示す証拠 | 迷子、異界の噂、記憶の混乱だけでは足りない |
| B4 | 根拠の食い違いが安全判断を左右する | 異様な外見や知らないこと一般とは区別 |
| C1 | 特定の本人の模倣・置換に関する疑い | 未知の人型怪物であることだけでは足りない |
| C2 | 味方・共同体の敵対的な利害・計画 | 強制された被害者はD3候補。援助者の知識不足は敵対でない |
| C3 | 訴えの拒否が必要な援助の不成立と結び付く | 訴えなかった、相手が驚いた、だけでは足りない |
| C4 | 当事者に重要な他者への将来の損失・救助課題 | 既に確定した死への悲嘆、関係の薄い人物への被害と区別 |
| D1 | 体内への侵入・感染を支持する接触・症状 | 背への外部付着、曖昧な憑依を内部侵入と断定しない |
| D2 | 当事者自身の身体変質と機能・自己像の損失 | 怪物側の異形や、自分の外傷だけでは足りない |
| D3 | 意図に反する行為を制御できない | 強制欲求・欲望の変容は行為制御と分けて記録 |
| D4 | 記憶・人格・存在の所有や継続を疑わせる証拠 | 記憶欠落だけで埋め込み・存在置換を断定しない |
| D5 | 内的な損壊の進行と、それに対する制御困難 | 外部からの切傷・処刑・自傷一般を包含しない |
| E1 | 条件と危険の起動関係を支持する根拠 | 単発の前後関係・伝聞を必要十分条件に昇格させない |
| E2 | 新しい被害対象へ及ぶ経路・媒介の証拠 | 怪異の移動、噂の流布だけでは被害伝播にならない |
| E3 | 有効な対処と重要な犠牲の必要関係 | 任意の費用、偶然の死、加害具を作る犠牲一般と区別 |
| E4 | 原因・対処規則は理解しており、実行資源が不足 | 単なる原因不明、専門家の動揺、実際に成立した援助だけでは足りない |
| E5 | 有効抑制・継続維持・放棄リスク・退出条件 | 単なる持続、再発予期、有限儀礼、逃避、怪異を育てる給餌だけでは足りない |
| F1 | 世界一般の基本規則への前提変更を支える証拠 | 局所的な接続異常B3や超常現象一件から一般化しない |
| F2 | 人間一般の認識・能力の構造的限界への証拠 | 一人の専門家の失敗や資源不足E4から一般化しない |
| F3 | 人間の価値の非中心性が当事者の前提を変える | 残酷な敵一人や、超常的な救済の存在だけでは足りない |
| F4 | 人間の成立・安全・歴史が他存在の用途に従属する証拠 | 一個体の宿主利用だけで人間一般の従属を認定しない |

E1の規則については「作中の真実」「当事者の信念」「読者が推測した仮説」を分ける。条件の必要性・十分性はそれぞれ未確認を許し、解除条件を起動条件の裏返しとして補作しない。E5は四条件のうち不明なものを明示し、逃げ続けるだけの状態を管理と呼ばない。F群は旧前提・新証拠・当事者の受容に加え、局所説明では足りない理由と代替仮説を記す。

### 3.8 v3のF群判定：前提変更と証拠の範囲

F群を判定する前に、旧前提、新証拠、その証拠が及ぶ範囲、当事者の受容・脅威認識、局所説明では足りない理由、代替仮説を記録する。本文中の観測、当事者の信念、語り手の主張、分析者の解釈は別欄にする。設計時にはGMが置いた設定と、探索者へ提示する根拠も区別する。

| 項目 | v3で陽性にするための確認 | 陽性にしない判断 |
|---|---|---|
| F1 | 基本規則に関する旧前提と複数の信頼できる新証拠があり、安全判断の変更が局所の迷路・時空異常だけでは説明できない | 一件の超常現象、局所的なB3、分析者だけの世界一般への拡張 |
| F2 | 工夫・反復検証と、個人・設備の不足に還元できない人間一般の構造的限界を支える本文根拠があり、その認識が当事者の前提を変える | 一人の失敗、有限回の失敗から永久の理解不能を推論すること、E4の資源不足 |
| F3 | 人間の価値や願いが世界で重視されるという旧前提が変わり、その非中心性を当事者が脅威として受け止める本文根拠がある | 一人の残酷な敵、悲劇的な結末だけから宇宙の無関心を推定すること |
| F4 | 人間の安全・成立・歴史と他存在の用途との依存関係が示され、個体の宿主利用や個別の陰謀を超える前提変更がある | 一個体の利用、敵の規模の大きさだけから人間一般の従属を認定すること |

F2の陽性は「人類に永久に理解不能だと証明された」という主張ではない。本文が支える範囲で、構造的限界に関する認識が成立する記述である。語り手の断言だけなら信念欄に残し、その正当化が不足する場合は非陽性の候補とする。有限回の失敗から一般的限界を補作しない。

F群が少なくなる理由は、資料の偏りと、他群より広い一般化・証拠要求の両方が考えられる。現データでは切り分けられない。未知資料でF群の候補と似た陰性例を別に点検し、分析一致と設計判断の差を調べる。F群を残したまま証拠要求だけを緩めて適合率を上げない。独自の設計上の利点がなければ、将来はMの補助タグへの変更も比較対象とする。

## 4. 五つの記述レイヤーと横断的な修飾軸

### 4.1 問題状態・世界モデル破綻・修飾軸・提示演出・情動反応を分ける

| レイヤー | 記録するもの | 判定での役割 |

| 予期的問題状態 | A〜Eの22項目、当事者・損失・根拠・対処・閉鎖条件 | 何が未解決で、どの設計判断が必要か |
| 世界モデル破綻 | F群の4項目、旧前提・新証拠・範囲・受容 | 世界や人間の立場に関する前提がどう変わるか |
| 修飾軸 | 期限、損失対象、可逆性、対処能力、接触経路、情報状態、世界層など | 同じ問題の下で判断・対処の条件がどう違うか |
| 提示・演出 | 感覚像、文章の速度、間、視点、音、提示順 | どの内容をどのように提示するか |
| 情動反応 | 恐怖、不気味さ、嫌悪、驚き、悲嘆、滑稽さ等 | 狙った反応と、発言・評定・行動等で観察した反応を分ける |

五レイヤーは独立した心理因子ではない。情報の提示順はDの認識やMの更新を変え得る。情動反応も設計判断に影響し得るが、演出を置いたことや型を付けたことから実際の反応を推定しない。

ホラー体験には予期的問題状態を持たない不気味さ、嫌悪、驚き、悲嘆、情動的な残響もある。型の欄を空欄にしても、提示演出と反応は記述できる。逆にA2などの問題状態があっても、興奮や技能の発揮として経験され得る。型の有無は怖さの有無の判定ではない。

Q／D／C／Mは五レイヤーとは別の簡略記法で、直列の工程でもない。Qの解明、Dの回避、Cへの決着、Mの更新は別々に生じる。「情報→Q→D→M→C」を必須順序としない。Qだけ閉じてDが残る場合も、Qが未解明のままDを回避する場合も記録する。

### 4.2 基本の修飾軸

| 条件 | 記録例 | 型との関係 |
|---|---|---|
| 切迫度・期限 | 今すぐ接触する／七日後に被害／時期不明 | A2もE1も、期限によって行動の余地が変わる |
| 観測可能性 | 見える／音だけ／当事者だけ見える／痕跡のみ | 透明な追手を独立した型にしなくても記述できる |
| 規則への確信 | 未知／証言のみ／部分実験済み／複数証拠 | 同じE1でも、未知の規則と既知の規則では選択が違う |
| 対処能力 | 手段あり／不足／代償付き／未発見 | 全ての型にE4の問題が重なり得る |
| 情報の主体 | 探索者／プレイヤー／観客／キーパー | 当事者は安心していても、観客が先に危険を知る場合がある |
| 損失の対象 | 自分／家族／町／関係／自己の継続 | 同じ追跡でも、誰を守るかで選択が変わる |
| 可逆性 | 元に戻せる／進行停止のみ／不可逆 | D2の治療と、変化後の態度の決着を分けられる |

### 4.3 開発調査から継承する修飾欄

| 修飾欄 | 記録例 | 過剰分類を防ぐ使い方 |
|---|---|---|
| 世界層・語りの範囲 | 夢内／現実／本編／追記／訂正／読者宛て | 夢内の危害を現実の因果にしない。訂正前の記述を確定設定にしない |
| 証拠の種類 | 観測／記録／伝聞／推測／訂正 | 分析者の解釈と作中事実を分ける |
| 接触経路・局面 | 内部侵入／外部付着／遠隔作用／接触前／接触後 | 外部付着をD1、突然の打撃をA2へ強制しない |
| 情報露出 | 所在／個体識別／秘密／公的露見。誰が知ったか | 追手の捕捉情報と評判・秘密の損失を区別 |
| 再発予期 | 再加害の根拠、期間、対象、抑制方法の有無 | 追跡なしの再発予期をA2・E5へ自動分類しない |
| 管理と退出 | 維持作業、抑制効果、放棄時の帰結、引継ぎ条件 | E5の継続義務と単なる危険持続を区別 |
| 関係の重要性 | 誰をなぜ守りたいか。設定／発言／分析者推定 | 他者の危害だけでC4を成立させない |

直接危害等は、型が付かなくてもDと局面を記述できる。「修飾欄に書ける」ことと「26型で説明できた」ことは別であり、未分類の残余を消さない。

### 4.4 演出と実際の反応

ジャンプスケア、暗闇、音楽、グロテスクな描写は、主に提示方法や感覚的効果である。26型と同じ段の箱に入れない。血の描写に、将来の損失や自己への含意が伴わなければ、嫌悪や驚きとして別途記録する。

目標階層、持続時間、影響範囲も分ける。「隠れる→資料を回収する→家族を救う」は包含関係を記せるが、家族への恐怖が長く続くこととは別である。町全体への被害は影響範囲の拡大であり、自動的な上位目標への遷移ではない。

## 5. 問題状態の遷移と世界モデル破綻への接続

A〜E内の型の交代、F群への前提変更、元の問題の解決は別に記録する。表のC2→F4は階層をまたぐ接続で、同格の型の交代ではない。追跡から閉じ込めへ移っただけでは、追手の危険は消えない。

| 遷移 | 何が閉じる／変わるか | 新しく開くもの | 設計上の点検 |
|---|---|---|---|
| B1→B2 | 現在地が分かり、Qは一部閉じる | 出口が使えないというD／C | 場所の解明を脱出成功として扱わない |
| A1→A2 | 発見の有無が確定する。発見回避は失敗 | 接触回避 | 恐怖の増幅だが、成功からの遷移ではない |
| A2→A1 | 距離・障害物によって接触を当面回避する | 捜索下での再発見回避 | 振り切った範囲と持続条件を明示する |
| C1→A2 | 検査で正体のQが閉じる | 正体を現した存在への対処 | 検査の成功を無効にせず、得た知識を使えるようにする |
| E1→E3 | 対処方法のQが閉じ、Dへの有効な選択が開く | 対処の代償への決断 | 解除条件と代償を区別する。意図的な罠なら証拠を設ける |
| D1→D2 | 感染の有無が確定する | 進行・不可逆性への対処 | 診断を治療成功とみなさない |
| E1→D5 | 危険の発動条件が分かる | 既に進む内部損傷への対処 | 発動源を遠ざけただけで損傷の停止・回復を保証しない |
| E1→E5 | 継続的な抑制方法が分かり、当面の被害を回避する | 管理の継続と離脱・継承の問題 | 条件付きの安全と恒久的な無害化を分ける |
| E5→C2 | 誰が管理を担うか、その実態が判明する | 責任逃れや危険の押し付けによる他者への不信 | 管理の負担と、他者を危険にさらした行為の評価を分ける |
| C2→F4 | 個別の敵対計画が分かる | 日常の成立目的についてのMの更新 | 単に敵の規模を大きくするだけでは成立しない |
| Dの回避→休息・終幕 | 特定の危険が実際に低下する | 新しい型を開かなくてもよい | 全ての成功を新たな罰に接続しない |

上表は因果的に作れる接続例であり、相性の良さの実証結果ではない。毎回「分かったせいで悪化した」とすると、調査を避ける学習を生む可能性がある。情報取得の成果、対処の成功、使える選択を明示する。

## 6. 既存作品による予備点検

### 6.1 資料と手順

作品の物語に関する事実と、本稿による型への割り当てを区別する。参照資料は末尾にリンクする。対象版を固定し、リメイクやシリーズ後続作の設定を混ぜない。

手順は、①場面または作品の中心的な問題を抽出、②損失・根拠・対処を確認、③型を割り当て、④Qの解明とDへの対処を分離、⑤分類だけでは説明できない要素を記す、である。

資料は網羅的な場面ログではない。以下の対応は代表的な問題の試験的な符号化であり、作品の全ての恐怖を説明したとは主張しない。映画・小説のCは人物の行動候補であり、観客・読者が選べる分岐ではない。

### 6.2 八作品の対応表

| 作品・対象版 | 適用する部分・中心的問題 | 主型／副型候補 | Q・D・C・Mの読み取り | 適合性・残る問題 |
|---|---|---|---|---|
| 『エイリアン』（映画、1979） | 宇宙船に入り込んだ存在が乗員を脅かす。体内から現れる場面 | A3／D1・D2 | 侵入者の把握と、船内の危険への対処を分離。身体の境界も破られる [S1] | 空間への侵入と身体への侵入を分けられる。造形・生理的嫌悪は分類外 |
| 『Alien: Isolation』（ゲーム、2014） | エイリアンの感知を避け、資源を使いながら生き延びる | A1・A2／E4 | 感知条件のQを使って回避Cを選ぶ。局所回避Dと任務目標は別 [S2] | ユーザー例の「見つかりそう」を記述しやすい。AIの挙動とプレイヤーの理解は別に測る必要がある |
| 『遊星からの物体X』（映画、1982） | 南極基地で、人間を模倣する存在が誰に潜むか分からない | C1／D1・D2・B2 | 正体を識別するQと、同化・孤立環境でのDが併存 [S3] | 「怪物の正体」と「誰が怪物か」を区別できる。終幕の曖昧さは安全を証明しない |

| 『イット・フォローズ』（映画、2014） | 歩いて迫る存在と、標的の移転・戻り | A2／E1・E2・E3 | 追跡規則Qを知っても、接近Dと標的移転の代償Cが残る [S6] | 規則が既知でも追跡は成立する。背景を見る視線や音楽の効果は分類外 |

| 『SOMA』（ゲーム、2015） | 人間だと考える機械、自己・意識・道徳的価値に関する問い | D4／B1・E3 | 身体的な危険と、自己理解M・難しい選択Cを分離 [S8] | 自己の恐怖を宇宙的恐怖と自動同一視しない。後者は前提・証拠・受容を追加点検する |

『CUBE』のB3については、参照ページにある公式クリップの「Moving in Circles」等を補助的に用いた。詳しい空間構造の分析までは行っていない。『リング』は参照ページに年の表示揺れがあるが、本文の1998年公開の説明と対象版を対応させた。

### 6.3 「理解すれば恐怖がなくなる」の反例候補

『イット・フォローズ』では、追跡者が歩くこと、姿を変えること、標的が移ることなどの規則が提示される。それでも逃走と判断は必要であり、標的が死ねば追跡が前の人物へ戻る。よって、Qの部分解明、Dの継続、Cの代償を同時に記せる [S6]。

これは「情報を与えない方が怖い」という一般論への反例候補になる。しかし、規則説明の有無を比較した実験ではなく、情報開示が恐怖を増すことの証明でもない。

『リング』も、本人が危険を逃れることと、他者への伝播を止めることが異なる。E1を本人について閉じる方法が、E2やE3の問題を残し得る [S5]。ここで分類が果たす役割は、解決の対象範囲を固定することである。

### 6.4 D4と宇宙的恐怖を分ける

『SOMA』の開発者説明は、他者について難しい選択をさせた後、プレイヤー自身を似た状況に置く構成を述べている。また、物語を体験しやすくするため、敵対的な遭遇をなくすSafe Modeが発表された [S9]。

この説明は、怪物との遭遇と、自己・道徳的価値をめぐる問いを分ける設計に対応する。ただし、Safe Modeでも同じ恐怖量が維持されたという実証にはならない。

D4は「自分は何者か」を扱う。F群は「人間について何を当然と思っていたか、その前提がどう変わったか」を扱う。D4に加えて別階層のF群を記録するには、自分一人の異常が判明する以上の前提変更が必要である。作品を哲学的と呼ぶことだけではF群の判定材料にならない。

### 6.5 宇宙的恐怖への直接適用：『クトゥルフの呼び声』

八作品とは別に、H. P. Lovecraftの短編『クトゥルフの呼び声』（1928年初出）を、F群の点検例とする。語り手は資料を突き合わせ、人間の知らなかった存在と歴史を理解する。ヨハンセンの航海記録では、その場の脱出と、存在について得た理解は別の帰結になる [S10]。

**分析上の解釈：** F2・F3の候補である。知識の統合が人間の立場を揺らし、語り手自身がその知識を脅威として扱うため、旧前提・証拠・受容を本文から点検できる。ただし、語り手が人間の理解限界を主張することと、人間一般に永久に理解不能であることの証明は別である。

この例では、A2的な局所逃走が成立しても、Mについて以前の理解が回復するとは限らない。巨大な怪物の登場だけをF群の根拠とする必要はない。

### 6.6 この適用で分かったこと・分からないこと

| 点検対象 | 今回の結果 | 残る検証 |
|---|---|---|
| ユーザー提示の三例の区別 | A1、A2、B1として、閉じる条件の違いを記せた | 実際のシーンログでも分析者が同じ分類をするか |
| 既知の規則と恐怖の併存 | 『イット・フォローズ』『リング』で記述できた | 規則開示の量・時刻が体験へ与える効果 |
| 識別と安全の区別 | 『物体X』の疑い・同化の問題を分けられた | 対象・時点・検査精度を固定した場面分析 |
| 身体の危険と自己理解 | 『SOMA』と開発者説明に対応する | 当事者が実際に何を脅威として受容するか |
| F群内の区別 | 短編でF2・F3の候補を記せた | F1・F4を含む別作品への適用と反例の探索 |
| 26型全ての必要性 | 未確認。今回の作品選定で全型を検証していない | 重複する型の統合、不足する型の追加 |
| TRPGでの有効性 | 未検証 | 選択可能性、判定、集団での情報共有を含む実プレイ |

作品を分類に合わせて選んでいるため、網羅性や一般性を支持する強い証拠にはならない。後付け分類が成功することは、「その型を使えば同じ恐怖が再現できる」ことを意味しない。

### 6.7 v1形成時のD5・E5導入経緯：『コトリバコ』の予備点検

初出スレッドを直接取得できなかったため、投稿本文の転載版の本編・追加報告を対象とする。後世の再話や派生作品は含めない。歴史的背景も作品内の設定として扱う [S11]。

現代の事件では、箱への接近で身体に影響が及び、専門知識を持つMがSの救助に当たる。後半では、危険物の長期保管・継承と、危険を知る管理者が他の家族へ負担を押し付けていた事情が説明される [S11]。

| 作品内の問題 | 主型・副型候補 | Q／D／C／Mの分離 |
|---|---|---|
| 知らずに危険物へ接近する | E1／A3 | 発動条件Qの認識と、現在の被害Dを分ける。日常の品への安全理解Mが変わる |
| 身体に影響が及び、内部損傷が脅威となる | D5／E1・C4 | 原因Qを知ること、損傷Dを止めること、他者を救うCを分ける。感染や身体変質に無理に分類しない |
| 専門家の知識・技能に救助を委ねる | E4〈候補〉／C4 | 対処方法と実行能力Cの不足を記録する。専門家の動揺自体は危険を知らせる提示方法 |
| 無害化まで長く保管・継承する | E5／E4 | 当面の安全Dと、管理を続ける責任Cを分ける。知識の取得だけでは管理問題は閉じない |
| 危険を知る者が、知らない家族へ押し付ける | C2／E5 | 事件原因Qの解明により、他者への信頼Mが変わる。事情の理解は責任の免除とは別 |
| 迫害への対抗手段に子どもを犠牲にする | E3／C4 | 作中の過去の選択として記録する。既に起きた残虐行為への嫌悪・悲嘆は分類外にも残す |
| 今回の対処後も、別の箱と謎が残る | E5・未解決Q／E4〈候補〉 | 今回の救助成果を固定し、別対象の危険と由来の問いを別IDで追跡する |

**v1形成時の導入理由：** D5は「侵入したものがある」というD1、「身体が別のものになる」というD2と、損失および対処条件が異なる。E5は「実行できる対処がない」というE4と異なり、対処できても継続を求められる状態を記す。この違いによって治療・進行停止、監視・継承・責任移管という準備項目が変わると考え、v1形成時に暫定的な独立型として導入した。v2・v3では既存IDとして維持する。

この予備点検ではF群を付与しない。呪いが存在すること、専門家が不安を示すこと、由来に未知が残ることだけでは、人間一般の構造的な限界や宇宙における立場の変更を示さない。また、物語を知るだけで呪いが伝わるとは本文ではされていない [S11]。

v1形成時に導入したD5・E5の独立性や設計効果は未検証である。別作品・実プレイでも既存型より有用な判断を生むかを点検し、追加価値がなければ統合・修正する。

### 6.8 洒落怖131項目を用いた開発過程と未検証事項

## 8. 設計語彙を評価するための次段階

### 8.1 部分適合を陽性支持から分離する

適合75・部分適合141・不適合17は歴史的な場面全体判定である。部分適合が最大のカテゴリーであるため、定義に一致しない例を吸収し、体系を反証しにくくしている可能性がある。副型、候補、修飾欄、型なしへ移せること自体を「説明成功」と数えれば、どの結果でも体系を支持できてしまう。

v3では型ごとに、必須条件を「根拠あり」「明示的に不成立」「資料から判断不能」に分ける。適合は、全必須条件に本文根拠があり、当事者・時点・世界層が一致する場合に限る。補助的対応を事前指定した場合は、その対応にも不一致がないことを要求する。必須条件に矛盾があれば不適合、判断材料が不足すれば資料不足とする。類似した候補を残す場合も非陽性であることを明記する。

部分適合は、対象範囲を固定し、全必須条件がその範囲で成立する一方、事前に定めた補助的な対応が一部一致しない場合に限定する。必須条件欠如の救済には使わない。何が対応し、何が対応しないかを条件単位で記録する。閉鎖が実際に達成されたことは必須ではないが、本文にない閉鎖条件を分析者が提案した場合は設計案欄へ分ける。

部分適合と候補は非陽性とし、適合へ合算した率を成功率にしない。主型・副型は役割の指定であり、それ自体を支持と数えず、型ごとに同じ適合条件を要求する。修飾欄で記述できた残余は、型による説明成功に算入しない。資料が十分でも予期損失がない場面は定義域外とし、予期損失があるのに既存型が足りない場面は未分類の問題状態として残す。

これらは新しい判定運用であり、既存141行を遡及的に厳格な部分適合へ読み替えない。実施前に各型の必須条件、補助条件、陰性例を固定する。補助条件を定められない型では部分適合を使わない。詳細は [評価計画](../../methods/v3-evaluation-plan.md) に記す。

### 8.2 未知コーパスをv3固定後に独立した人間評価者が再符号化する

v3文書、必須条件表、場面の区切り方、対象範囲、判定欄、分析手順をcommitとハッシュで固定してから、開発に使っていない本文と版をtest用に確保する。今回の131項目、旧版の例示作品、同じ話の異名・系列・転載をtestへ混入させない。独立性を確定できない資料は保留する。共通の資料源・文化圏や作品内場面の相関も考慮し、233場面行を独立標本と扱わない。

複数の独立した人間評価者が、同じ固定資料を相互の判定と過去のAIラベルを見ずに符号化する。まず当事者・予期損失・根拠・行動・前提を記録し、次にA〜EとF群を別々に判定する。訓練と手順調整には開発用資料を使い、test結果を見て定義を変更しない。結果を受けて改訂する場合は次版として扱い、新しいtest資料を必要とする。

### 8.3 分析者間一致と、設計語彙の変更条件

複数ラベル、型ごとの陽性・陰性・保留、A〜E内の主型・副型、F群の前提変更について、合議前の一致を評価する。低頻度のF群では、両者がほぼ陰性でも高い単純一致になり得る。陽性例・陰性例・欠測を分け、型別の混同と根拠の違いを報告する。場面の切り方の不一致と、同じ場面での型判定の不一致も分ける。一致度指標、集計単位、保留の扱い、判断基準はtestを見る前に固定する。現時点で一致度の値はない。

| 判断 | 独立資料と設計比較で検討する結果 |
|---|---|
| 型を統合する | 区別しても必要情報、行動、準備項目が変わらず、符号化で混同が続く |
| 型を分割する | 同じ項目に入れた場面で必要な対処や決着条件が繰り返し異なる |
| 型を追加する | 重要な予期損失が未分類として残り、修飾だけでは設計判断を説明できない |
| 型を補助タグへ下げる | 他項目への修飾やMの記述で足り、独自の設計判断を生まない |

E4と対処能力軸、C4と損失対象軸、F群とMの補助タグを比較する。D5とD1・D2、E5とE3・E4についても、対処方法・決着条件・準備項目の差を評価する。IDを残す都合を独立性の証拠にしない。

### 8.4 GM設計支援効果を比較する

同じ設計課題で、v3を使う条件と使わない条件を比較する。作成物について、必要な根拠の欠落、使える選択、Qの解明とDの回避の混同、成功範囲の明示、準備時間・負担を評価する。v3条件の作成物を評価する採点基準を、26型の記入数だけで構成しない。条件を知らない評価者が設計物を判断できる手順を用意し、GMの経験、順序、課題難度を扱う方法も事前に決める。

A1とA2、D1とD5、E4とE5などを区別したとき、感知根拠と接触経路、検査・摘出と進行停止、実行資源と継続管理の準備が実際に変わるかを点検する。閉鎖条件が違うという定義を繰り返すだけでは設計効果を支持しない。

### 8.5 プレイヤー体験差を独立に調べる

GMの準備が変わることと、プレイヤーの体験が変わることは別の仮説である。危険認識、予期した損失、可能だと思った行動、怖さ、不気味さ、嫌悪、達成感、納得、主体性を分けて観察する。型が付く場面で恐怖が生じない結果も保持する。

設計語彙の利用効果を比較する試験と、情報・選択・演出を変える試験は区別する。後者では同じ問題状態で提示だけを変える比較と、提示をそろえて情報・選択を変える比較を分ける。脅威の強さ、時間、判定難度、GMの進行を扱う方法を事前に定める。解決・非解決・損失による終結を単一の良い体験にまとめない。

本章は未実施の計画である。未知コーパスの選定、独立評価者、標本数、指標、効果量、採否基準の具体値は未決定であり、実施済みの結果として補完しない。詳細な固定・集計・比較の手順は [v3評価計画](../../methods/v3-evaluation-plan.md) を参照する。

## 9. 適用上の限界

本稿は、驚き、嫌悪、悲嘆、不気味さ、人物への共感を十分には説明しない。また「追われる」という問題状態は、ルールが安定して対処能力が高ければ、恐怖より興奮や技能の発揮として経験され得る。

映画や小説では、人物が誤解し続ける展開や、脱出不能の結末が成立する。しかしTRPGへ移す際に、プレイヤーの検証・拒否・離脱を封じて同じ展開へ導くことは、物語の再現と引き換えに選択の実効性を失わせ得る。移植するのは固定された筋書きではなく、問題、証拠、世界条件、行動の帰結である。

旧版の作品は分類を試すために選んだ例であり、追加調査も特定の洒落怖一覧に依存する。本文不足、転載改変、系列内の範囲、異名・重複の留保がある。AI担当5群と統合担当AIは同じ基準と開発文脈を共有しており、判断誤差が相関し得る。モデル構成や誤差相関の程度は現資料から確定できない。群の一致や提出数を独立評価者数に読み替えない。独立した全編分析と再符号化、別資料での比較、実プレイの検証が必要であり、26型を完成済みの体系として扱わない。

## 10. 結論

本稿の26型は、ホラーTRPGに利用可能な予期的問題状態と世界モデル破綻を記述する操作的な設計語彙である。A〜Eの22項目とF群の4項目を分け、修飾軸、提示演出、情動反応を別に記録する。問いが解明された成果、安全を得た成果、選択への決着、世界理解の変化も分ける。

開発資料上では記述できる例と適用境界の問題が見つかったが、26項目の網羅性・最小性・独立性、自然分類としての妥当性、GM設計支援効果、プレイヤー体験差は未実証である。部分適合を成功へ合算せず、F群の広い一般化を局所的失敗から補作せず、型なしの不気味さと未分類の問題状態を保持する。

次段階ではv3を固定し、未知コーパスを独立した人間評価者が再符号化する。分析者間一致、GMの設計判断、プレイヤーの反応をそれぞれ評価し、区別の価値が確認できない項目は統合・補助タグ化も検討する。検査合格と文書提出の完了を、これらの研究上の検証完了と同一視しない。

## 付録：予期的問題状態・世界モデル破綻カード（v3）

| 項目 | 記入する内容 |
|---|---|
| 基準版 | v3文書と判定規則の固定commit・ハッシュ。過去のbaseline_idを置換しない |
| 問題ID・型 | A〜Eの主型候補と副型。分類根拠。型なし・定義域外・保留を許す |
| 世界モデル破綻 | F群を別欄へ。旧前提・新証拠・適用範囲・受容・代替仮説。局所M更新と区別 |
| 資料の範囲 | 対象版、本文範囲、作品／場面ID、出典、本文確認状態 |
| 当事者 | 誰が知り、誰が危険を受け、誰が選ぶか |
| 損失D | 何を失うか。切迫度・対象範囲・発生条件 |
| 問いQ | 何が分からないか。答えが分かっても何が残るか |
| 選択C | 行動候補、実行条件、既知の帰結、代償 |
| 前提M | 変わる前提と証拠。なければ「変更なし」とする |
| 情報／提示／出来事 | 命題、取得経路、世界の変化を分ける |
| 閉じる条件 | Q・D・C・Mのどれを、どの範囲で閉じるか |
| 範囲 | 目標の包含関係、持続時間、影響範囲を別記する |
| 遷移・成果 | 次の型、残る問題、確定させる成功 |
| 別経路 | 情報の拒否、早期取得、見落とし、離脱への対応 |
| 修飾軸 | 期限、可逆性、情報露出、接触経路、再発予期、管理・退出条件 |
| 証拠層・世界層 | 観測／伝聞／推測／訂正。本編／追記、夢内／現実を分ける |
| 提示・演出 | 感覚像、視点、速度、間、音、提示順。狙いと効果を分ける |
| 適合判定 | 型ごとの必須条件と根拠。不成立と判断不能を分ける。部分適合・候補は非陽性。確信度・対立仮説も記録し、場面全体と型ごとの判定を混同しない |
| 残余 | 未分類の問題状態、追加型候補、定義域外、資料不足を区別。修飾で記述できても型の支持へ算入しない |
| 情動反応 | 怖さ、不気味さ、嫌悪、驚き、悲嘆、滑稽さ等の狙いと確認した反応を分ける。観察方法・未測定も記す |

### 最小カードと記入例

実際の準備では全欄の記入を必須にしない。「問題・損失／根拠／使える選択／閉じる範囲／演出と観察」の五欄から始め、分類判断が曖昧なときに拡張する。

以下はv3の記入法を示す**架空の設計例**で、研究対象作品の事実ではない。

| 欄 | 例A：倉庫の内側に何かを封じている |
|---|---|
| 問題・型 | 毎夜の封印更新を止めると周辺住民が襲われる。E5候補。外から包囲されていないのでA4は付けない |
| 損失と根拠 | 過去の更新失敗と被害記録。関係は部分確認で、唯一の抑制手段かは不明 |
| 修飾軸 | 継続管理、毎晩の期限、現実の本編、記録と当事者証言 |
| Q／D／C／M | 抑制方法Qは部分判明。今夜のD低下と管理義務Cを分離。安全が作業に依存するM |
| 閉じる範囲 | 今夜の更新成功を認める。恒久無害化または同意・能力を備えた引継ぎは別目標 |
| 演出・観察 | 更新時刻へ近づく音を演出する。負担感や怖さが実際に生じたかは発言・終了後評価で確認 |

| 欄 | 例B：無人の車内に異様な人影が密集している |
|---|---|
| 問題・型 | 接近・加害・模倣・知覚矛盾の根拠は未提示。型なし |
| 損失と根拠 | 具体的な予期損失は未確認。作者が危害を後付けして分類しない |
| 提示・演出 | 人数と空間の不釣り合い、顔の向き、無音を記録 |
| Q／D／C／M | 正体のQは開き得る。DとMの変更は未確認。退避・観察というCは可能 |
| 観察 | 不気味さ、好奇心、滑稽さ、無反応を許す。反応を測るまで「怖かった」としない |
| 後続 | 人影が追い始めれば、新しい時点でA2を判定する。前の場面を遡って追跡扱いにしない |
