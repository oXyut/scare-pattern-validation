本文は独自に要約し、長文の転載はしていません。出来事・伝聞・夢・映像・語り手の推測と、編集による恐怖の解釈を分けます。物語の時系列と語られる順序が違う作品には順序の説明を付け、内側の怪談や独立候補は別の流れにしています。

v1の全131作品・258場面（本文不足25行）・166出典・26型、および別版の追補39件は変更していません。元の公開投影（あらすじ欄を除く）は承認済みPoCのSHA-256と一致します。今回追加した8URLはv1の出典IDを借用せず、本文未確認だったv1の分類を新設しません。v3の案や評価計画を検証済みとは扱いません。
