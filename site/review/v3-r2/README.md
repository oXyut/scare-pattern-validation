## 表示する結果と範囲

標準表示は追加調査r2。調査版で初回r1へ戻れ、版の表示でv1・v3・比較を選べる。選択はURLへ保存し、再読込・戻る・進むで復元する。以前のr1の本文根拠URLは、版指定がなくてもr1の保存データを選ぶ。

r2では110作品の選定118記録について、必須条件の根拠が揃う型を日本語名で先に示す。当事者・時点・予期する損失・認識・本文の層・限界を併記し、条件ごとの根拠あり／明示的不成立／証拠不明と、その本文箇所へ進める。A〜Eの問題状態とFの世界モデルを分け、Fの旧前提・新証拠・一般化・代替仮説を読む導線を置く。条件未確定を作品全体の陰性にしない。主型・副型の順位と部分適合は追加しない。

比較は旧場面ごとに同一当事者・時点／範囲の重なり／未抽出／本文保留を示す。未抽出104場面は削除・不成立にせず、対応するr2記録がないまま理由を表示する。旧候補外の成立型も選定範囲の差として示し、作品全体の追加・削除・適合率としない。

限定18作品と本文・同定保留21作品を保持し、保留作品には作った場面・条件判定を置かない。既存あらすじ110作品だけを一覧で表示し、保留21作品を空欄のままにする。v1の本文状態92/14/25と後発あらすじ92/18/21は別に表示する。型名と6上位分類名・色は現行v1の名称とアクセントを使うが、型の意味・判定はv3条件から独立に読む。

9,204は選定記録×異なる必須条件の入力数で、独立観測数ではない。単一AI・非盲検の開発資料点検、独立符号化・一致度未実施、全場面・原投稿一致・全シリーズ未確認の留保を表示する。

## ローカルで開く

```sh
python scripts/build_v3_site.py
python -m http.server 8000 --bind 127.0.0.1 --directory docs
```

`http://127.0.0.1:8000/v3.html?edition=r2&version=compare#G05-W18` が八尺様の比較。`edition=r1` が保存した初回、`version=v1` が旧判定、`version=v3` が選定記録の表示。現行v1へは画面上のリンクで戻れる。今回の表示変更は公開サイトに未反映。
