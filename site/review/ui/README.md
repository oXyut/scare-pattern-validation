# 現行UIの表示改善レビュー

基点はPR #21のマージコミット `09876cfaba2fb421ac28a5f805bc47c08cf21427`。v3調査とは独立した表示の変更です。このブランチはmainへマージ・本番公開していません。

## 変更

- 利用者向けの追加・拡充の経緯、次の評価計画、テンプレートの準備状況を外し、結果・定義・確認範囲を中心にしました。分類資料の本文状態とあらすじの参照範囲は区別します。監査履歴・研究資料・過去のレビューは保持します。
- 四つの分析欄は元のv1定義に沿って「問い」「危険」「選択」「世界モデル」を日本語で説明します。本文の人物イニシャルCやD子は、分析の略号と取り違えません。
- 六つの分類の見出しと26型は元の名称を使います。例：`A2`は画面では「追われている」。一覧、型フィルタ、型辞典、場面記録、タイムラインで同じ名称を表示します。検索は型名・分類名にも対応します。
- 一覧に110件の短いネタバレありのあらすじを掲載。既存の発端・展開・結末から完全な文を抜粋し、独立候補や複数篇5件は同じ要約の内容から専用の短文にしました。18件の範囲限定と21件の未掲載を明示し、詳細のあらすじ・時系列または未確認理由と出典へ進めます。
- 承認済みの細い縦軸・丸いノード・整列カードは維持しています。識別子はデータ、URLパラメータ、既存アンカーに残します。
