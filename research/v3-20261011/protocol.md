# v3 開発資料再点検 r1

対象開始版：`09876cfaba2fb421ac28a5f805bc47c08cf21427`。対象は固定131割当。
この手順は既存 codebook 案の開発運用であり、未知資料による独立評価計画の開始条件を満たしたとは扱わない。

## 実際に行う手続き

単一 AI が既存あらすじ・時系列・出典レビュー・境界監査を読む。過去のラベルも閲覧済みで盲検ではない。最初に猿夢、八尺様、夢魅、リゾートバイト、チガヤ、やまけらし様の代表箇所を再閲覧し、当事者・時点・世界層と条件の記録を点検する。その後、全131割当へ展開する。人間評価者、別の独立符号化、一致度、GM比較、体験測定は実施しない。再閲覧と既存レビューの利用を別欄に記す。

全131件に、26型それぞれの全共通・型別必須条件を記録する。範囲が広い作品では場面を選んで点検するため、選ばなかった場面の型の不存在・作品全体の網羅を主張しない。各作品に具体的な未解決事項を残す。既存110あらすじ（指定範囲92・限定18）と21保留の区分を独立欄に保持する。保留作品には物語や当事者を作らない。

判定は supported / explicitly_false / unknown。必須条件が全て supported なら fit、少なくとも一つ explicitly_false なら not_fit、残りは pending。空欄や不出現を否定へしない。補助条件は未固定で partial は使用禁止。主型・副型とも全必須条件を満たす必要がある。中心性は効果測定していないため、成立した型にも主副の順位を強制しない。

旧ラベルから新ラベルを算出しない。今回 AI が個別に行った条件別判断を `review-notes.json` に先に書き、生成器は条件集合の展開と整合性・集計だけを行う。未記入条件は unknown とし、条件の文言と、その作品の確認範囲・不足点を理由に残す。これらは陰性例ではない。

## 証拠と範囲

根拠は短い自作要約、版、出典レビューID、時系列 step ID、証拠層を記す。narrated は作中語り手の直接経験の記述であり、現実の事実確認ではない。reported、dream、vision、embedded_story、inference を区別する。今回の再閲覧は URL と新 UTC、確認した投稿・段落の範囲を記録し、過去の取得時刻を置換しない。

既存あらすじが明示しない因果支持、当事者の予期、本人性、体内位置、継続管理の効力や退出条件は保留する。E1 の伝聞規則を客観的な必要十分条件へしない。F は旧前提・新証拠・範囲・受容と脅威・局所説明が足りない理由・代替仮説を別欄に記す。局所説明で足りる可能性は全般的陰性の証明ではない。

Q の解明、D の回避、損失による終結、観測終了、一時的な抑制と恒久的無害化を分ける。閉鎖を達成しなかったことは適合の欠点にしない。

## 差分・保護・公開

v1 の基準、割当、群別記録、台帳、統合集計・snapshot を保持する。既存 UI ファイルには変更を加えず、`v3.html` を独立した比較入口にする。v1 ラベルは歴史的候補／場面全体判定、新 v3 は選定場面での型別必須条件判定と表示し、二値の増減や成功率として比較しない。

入力の commit と SHA-256 は `inputs.json` に保存する。再現用生成器は通信しない。本文の転載・長い引用・ローカル絶対パス・認証情報を公開しない。全件記録の存在・検査成功は分類の独立検証、怖さや設計効果の証明ではない。

## 基準上残る問題

- E1 の因果支持の最小証拠水準は未固定。単発の前後関係だけなら unknown。
- C4 の重要性、D2 の自己像・機能損失と受容、E5 の管理効力・放棄・退出条件が欠ける記録は unknown。
- F の世界／人間一般への一般化と代替説明の排除は未確定。局所の怪異を陽性へ一般化しない。
- 補助条件、人間評価の場面区切り・指標・標本設計等の固定は別の将来手続きである。
