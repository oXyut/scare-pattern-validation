# 記録様式と受入条件

設計段階です。`templates/`のJSONはすべて未記入です。`null`は未測定・未固定・未同定を示し、0や空文字へ置換しません。空配列は記録行がまだない状態です。テンプレート中の`pending`は未実施の既定値です。

## 記録の関係

| record_kind | 記入単位と主要欄 |
|---|---|
| study_plan | 1固定計画。役割分担、参加・保管条件、gate、固定ファイルのcommit／SHA-256、study別のN・仮定・指標・判定・欠測・多重性・未決事項 |
| corpus_candidate | 選定候補1件。版・範囲・本文状態・系列・抽出、7除外区分、採否・理由、選定前固定への参照 |
| annotation | 人1人×同一場面。匿名ID、資料ハッシュ、codebook条件一覧、主／補助一致度の単位指定、範囲、Q/D/C/M、26型の条件根拠と判定、残余、盲検、封印 |
| adjudication | 相違1件。原記録とハッシュ、合意前一致度保存物、相違条件、根拠、裁定、未解決理由 |
| gm_evaluation | 独立採点者1人×設計物。匿名の設計物・GM・課題・採点者、blind条件、5項目、準備時間、負担と欠測 |
| experience_observation | プレイヤー1人×時点。卓・GM・場面・匿名参加者、別実験の条件ID、測定時点、11尺度、結末と中断・欠測 |
| decision_report | 仮説1件。study、主指標と測定目的、単位、入力ハッシュ、合意前／後の別、予定Nと実際N、分母・欠測・逸脱、区間と判断 |

研究IDは実施者が作る匿名の研究内IDです。アプリの会話・session ID、氏名、連絡先、認証情報、ローカル絶対パス、内部作業記録は収録しません。非公開の対応表と同意記録をrepo外で管理します。実データは既存無視対象の`private/`へ置く想定です。公開前には短い自作分析と出典リンクへ範囲を絞り、本文の長い引用を含めません。

日時は実際に行った確認・選定・封印の日時だけをISO 8601で記録します。未知なら`null`と理由です。資料の現在の取得時刻から過去の取得時刻を補いません。本文未確認と本文確認済みの陰性を混同しません。

## 型別記録

`codebook_conditions`は固定codebookから複写する型ID・必須／補助条件IDの一覧です。ここで条件を創作しません。`type_judgments`は26行で、`required_evidence`に全必須条件を1回ずつ記します。`met / contradicted / unknown`に加え、根拠位置、要約、`observed / reported / inferred / unavailable`を残します。

`fit`は全必須と全指定補助条件がmetです。`partial_fit`は全必須がmetで、事前指定補助条件にcontradictedがあり、unknownがありません。補助条件なしでは使えません。`not_fit`は必須条件にcontradictedがあり、その否定根拠が必要です。残りは`pending`です。主型・副型・候補はA〜Eだけに記し、F群は`world_model`欄に分けます。候補役割は陽性にしません。

`closure_design`は設計可能な対処、`closure_observed`は本文が実際に示した決着です。F陽性は`world_model_evidence`の6項目を埋めます。型なしの不気味さ・未分類問題・資料不足は`scene_status`と`residue`に残します。`blindness_breach=true`の記録は、盲検の主解析に入れず逸脱として保持します。

## 検査の境界

`schema.json`はDraft 2020-12のJSON Schemaです。同梱検査器はこのファイルで使う限定したキーワードだけを実装しています。汎用JSON Schema処理系ではありません。未知キーワードを追加した場合は検査器がエラーにします。検査器は通信・書込みをしません。

テンプレート検査では未記入を許しますが、実測値や封印日時が混入したテンプレートを拒否します。`--record`でも保留の記録は受け入れます。開始準備の合格を求める場合だけ`--ready`を使い、未決事項・未通過gate・数値や尺度の未固定をエラーにします。型条件の根拠、独立性照合の真偽、同意の実在はスキーマで証明できません。

## 実施者による受入

| 段階 | 人間が確認する受入条件 |
|---|---|
| 開始前 | 役割兼務、参加・撤回・保管条件、全固定ファイル、G0〜G3、study別のNと根拠・指標・閾値・主比較・欠測・多重性が決定。本文閲覧前に固定 |
| 選定 | 全候補・抽出枠・順序・seed・確率と7除外区分が追跡可能。除外と保留を含め分母が再現できる。版・系列は別に同定 |
| 符号化 | 固定資料とcodebookのハッシュ照合。割当全件が提出または理由付き未提出。全必須条件と26型の欄、盲検、陰性・残余・欠測を保存 |
| 一致度 | 相互相談前の原記録、解析プログラムと版、入力ハッシュ、cluster単位、全分母・陽性一致・混同表・保留理由が再現可能 |
| 調停 | 合意前解析を先に保存。独立記録を変更せず裁定を別保存。調停の未解決とcodebook改訂候補を隠さない |
| GM | 条件割当・経験層・課題・時間範囲、独立blind採点、欠落根拠と時間・負担を再現できる。型記入数は成果にしない |
| 体験 | GM試験と別ID・仮説・記録。卓割当、一要因操作、尺度と時点、GM／卓相関、途中終了・未回答を保持 |
| 判定 | 予定N・実際N・仮定、区間、欠測、逸脱、支持／失敗／保留の理由を示す。未実施は観測値・判定null。構造検査を効果の証拠にしない |

検査用の人工記録は`tests/`内のメモリだけで生成します。人間の符号化・観測・研究結果として公開しません。
